# Glossari de traducció

Criteri: els **noms propis de lloc i de persona** queden en català (el Miracle, la Bassadòria, la Cirosa, les Gírgoles, Sant Benet, Sant Antoni, Ineu, Runna...). Els **noms comuns** que fan de nom de lloc es tradueixen (la Plaça, el Cementiri, les Cel·les). Els tractaments es tradueixen (Pare, Germà, Senyor). Els personatges-concepte es tradueixen (l'Ocellaire, el Gran Til·ler, l'Home del Raïm).
